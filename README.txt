FDS MUSIC SAMPLE TESTER — GITHUB PAGES READY
===========================================
A completely static (HTML / CSS / JavaScript) website.

PUBLISH ON GITHUB PAGES (FREE PUBLIC REPOSITORY):
1. Make or sign into your GitHub account: https://github.com
2. Visit https://github.com/new to create a repository.
3. Repository name: fds-music-survey
4. Choose Public, then click Create repository.
5. Extract this ZIP file on your computer.
6. In the new repository, click Add file > Upload files (or the upload-files
   link on an empty repository).
7. Upload the CONTENTS of the extracted directory, not the directory as a
   nested folder. index.html MUST appear at the repository top level alongside
   style.css, script.js, and sample_new_students.csv.
8. Click Commit changes.
9. Open Settings > Pages. Under Build and deployment, Source:
   Deploy from a branch. Branch: main. Folder: /(root). Click Save.
10. After publishing, open the URL shown in Settings > Pages:
    https://YOUR_GITHUB_USERNAME.github.io/fds-music-survey/

Check the website in Chrome. You can share the URL without Netlify.
You may optionally connect a purchased custom domain in Settings > Pages.

BE AWARE:
- This is a client-side app: tests run in each visitor's browser.
- Do not upload personally identifiable survey data to a public repository.
- Only the included fictional demonstration CSV is included here.
- Your reference is an earlier cleaned synthetic survey workbook: do not
  generalize statistical results to real college populations.

Included files:
  index.html                 Website entry point
  style.css                  Responsive page styles
  script.js                  Statistical tests and CSV upload handling
  sample_new_students.csv    Fictional sample data
  .nojekyll                  Tells GitHub Pages to skip Jekyll processing
  README.txt                 This instruction file
